## Virtual laboratory

`virtual-lab.html`, `virtual-lab.css`, and `virtual-lab.js` implement three Arabic educational cases (anemia, urinalysis, Gram stain), with 15 graded steps, explanations, review, and local progress. Case links use `#anemia`, `#urine`, and `#gram`. Related courses link to these cases from the student portal.

Content is fictional training material pending instructor review, not a clinical or competency assessment. Schematics are original illustrations, not patient images. Each case links to its references.

Progress is stored only in the current browser under `mlt-virtual-lab-v1`; no login, personal information, or server submission is involved. An 80% score earns a motivational badge. Retrying preserves the previous best. Bump the content/storage version when changing answer keys. The service worker caches only explicit public application assets and uses the network first.
